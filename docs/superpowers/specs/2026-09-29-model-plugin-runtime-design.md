# 模型插件运行时设计（图像超分工具首期）

## 目标与范围

桌面端在 Windows x64 和 Linux x64 上提供可视化的单图超分流程。首个模型插件使用 Real-CUGAN 官方 PyTorch 实现，支持 CPU 和 NVIDIA CUDA，允许用户选择本地权重文件或从插件给出的官方地址获取。插件拥有参数界面、依赖声明和模型来源；宿主提供 Python 环境、文件选择、安装、任务与进程管理。

首期不处理视频、批量任务、多 GPU 调度和其他加速后端。模型文件不打进应用安装包。Linux 打包仍沿用现有 Forge 路径；本功能不改变整个应用的发行流水线。

## 边界

- 插件的 UI 仍运行在 sandboxed WebContentsView 中，只能调用 SDK 白名单 API。
- Python 安装、pip 安装和推理是本机代码执行。宿主只向真实内置插件开放 `models.execute`；未来官方签名插件需增加固定的发布者公钥信任根，不能把任意自签名的 `signatureVerified` 当作官方身份。
- 宿主从自己创建的 runtime identity 取得插件 ID；不接受插件传入另一个插件 ID、任意脚本路径、任意命令行或任意 Python 包名。
- 插件 manifest 声明 Python 版本、相对脚本路径和 CPU/CUDA 依赖。宿主验证路径、依赖形状与权限，运行时再次核对安装记录和文件真实路径。
- 运行前显式选择输入图片、模型权重和输出目录；宿主返回不含本地路径的临时文件句柄。输出文件名由宿主生成。插件停用或应用关闭时停止其进程并释放句柄。

## 环境与任务流程

1. UI 查询本机 Python 和 Conda 环境。宿主先检查 PATH 和常见 Conda 安装位置，验证实际解释器版本。用户可选择现有 Python/Conda 作为创建插件私有环境的基础。
2. 若无可用解释器，UI 提供安装 Miniforge 的操作。宿主从官方发布地址下载固定版本的 Windows/Linux 安装器，按预置 SHA-256 校验后静默安装到应用私有目录，不改系统 PATH。
3. 宿主在应用数据目录按插件 ID 创建独立环境。依赖只读取当前安装版本的 manifest，并根据 CPU/CUDA 选择固定包组；依赖安装作为可取消任务显示状态。
4. 插件页面让用户选择权重、输入图和输出目录，配置倍率、设备、tile 与半精度。宿主把授权路径和经过校验的参数作为 JSON 传给插件包内的 Python 入口。任务状态通过现有 JobService 事件返回。
5. 图像超分工具插件首期包含上游 MIT 许可源码和薄包装脚本。包装脚本用官方 `RealWaifuUpScaler` 推理，图片读写由 OpenCV 完成。加载权重必须使用 PyTorch 的安全权重加载模式。

## 错误与验证

环境不存在、版本不符、校验失败、依赖安装失败、CUDA 不可用、权重不匹配、输入图片损坏、进程退出异常，均显示可操作的错误；取消会终止对应子进程。宿主对运行数量、输出日志长度与安装器来源做限制。

验证包括：manifest 与权限拒绝测试、解释器发现和进程取消测试、路径/句柄越权测试、Real-CUGAN 包装脚本的参数和输出测试、TypeScript 类型检查、插件构建和桌面主进程构建。真实权重的 CPU/CUDA 端到端推理需要在装有 PyTorch、对应设备和官方权重的目标机器执行，并单独记录结果。
