# GuYanTools Plugin

Run `pnpm install`, then `pnpm run dev` for local development. For a production archive, run `pnpm run build`, `pnpm run validate`, then `pnpm run pack`.

The template uses `@guyantools/plugin-cli` for build and packaging and `@guyantools/plugin-sdk` for API types. The sample UI uses only Vue or React so it can build before adding optional GuYanTools UI components.
